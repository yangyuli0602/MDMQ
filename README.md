# MDMQ · 巨量结构化数据合并与查询

一个免安装的 Windows 工具，用来处理 Excel 打不开、打开就卡死的超大结构化数据。

**不做数据清洗** —— 只做三件事：

1. **导入**：Excel / CSV / Parquet / DuckDB / SQLite / YXDB，多种来源合并成一张表
2. **查询**：写 SQL 查数，也可以用一句话让 AI 帮你写 SQL
3. **导出**：结果导成 Excel / CSV / Parquet

## 下载

到 [Releases](../../releases/latest) 页面，下载最新的 `MDMQ_vX.X.X_日期.zip`。

- 约 133 MB，解压后约 388 MB
- **免安装**，不需要装 Python
- 支持 Windows 10 / 11（64 位）

## 使用

1. 解压到任意本地目录（**不要放 OneDrive、网盘、U 盘**）
2. 双击 `MDMQ.exe`（首次启动 5–10 秒）
3. 详细说明见压缩包里的 `使用说明.txt`

## 升级

**方式一：程序内一键更新（推荐）**

点右上角「检查更新」→ 发现新版本 → 点「立即更新」→ 下载完成后程序自动关闭、替换、重新打开。设置和 AI Key 会自动保留；替换失败会自动回滚。

**方式二：手动**

1. 从 Releases 下载新 zip
2. 解压前先把旧目录里的 `settings.json` 拷出来（里面有你的设置和 AI Key）
3. 用新目录替换旧目录，把 `settings.json` 拷回去
4. 双击新的 `MDMQ.exe`

程序启动时不联网，只有点「检查更新」才会查一次。
